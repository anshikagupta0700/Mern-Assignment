CSS Overflow Property

Learn how to handle extra content inside a box.

Overflow Visible

This is a long paragraph. The content will come outside the box because overflow is visible. Extra content is not hidden.

Overflow Hidden

This is a long paragraph. The extra content will be hidden when it goes outside the box. You cannot see the remaining text.

Overflow Scroll

This is a long paragraph. You can scroll inside this box to read all the remaining content. Scrollbars are displayed.

Overflow Auto

This is a long paragraph. A scrollbar will appear only when the content overflows. You can scroll to read everything.

CSS Overflow Properties

1. Visible: Extra content is displayed outside the box.

2. Hidden: Extra content is hidden.

3. Scroll: Scrollbars are provided to view extra content.

4. Auto: Scrollbars appear when required.
